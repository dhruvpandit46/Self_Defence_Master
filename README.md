**Self-Defense Master** is a comprehensive personal safety guide built with **HTML5, CSS3, and vanilla JavaScript**.

This interactive guide covers essential self-defense principles, practical techniques, common attack scenarios, injury recovery protocols, and the psychology of self-defense. Designed for complete beginners, it provides actionable knowledge to help you stay safe in various situations.

The project requires **no frameworks, no backend, no database, and no build tools**. It runs directly in a modern web browser.

## 🎯 Defense Techniques Covered

### Basic Strikes

| Technique | Target | Description |
|-----------|--------|-------------|
| 👊 Palm Strike | Nose/Chin | Strike with base of palm |
| 🦵 Groin Kick | Groin | Kick upward forcefully |
| 💪 Elbow Strike | Face/Ribs | Close-range strike |
| 🏃 Escape & Run | N/A | Create distance and flee |

### Vulnerable Targets

- **Eyes** - Disorient with a poke
- **Nose** - Causes tears and confusion
- **Throat** - Disrupts breathing
- **Groin** - Extremely sensitive area
- **Knees** - Side kick to disable movement

## 📱 Scenario-Based Learning

### Scenario 1: Wrist Grab
```text
Action: Twist arm toward attacker's thumb (weakest point)
        Strike with free hand
        Run to safety

Avoid: Don't pull straight back
       Don't freeze in panic
```

### Scenario 2: Front Approach
```text
Action: Create distance immediately
        Use firm voice: "STOP! BACK AWAY!"
        Target vulnerable areas if they continue
        Escape

Avoid: Don't turn your back
       Don't engage in conversation
```

### Scenario 3: Being Followed
```text
Action: Change direction or cross street
        Go to crowded, well-lit area
        Call someone and speak loudly
        Enter a store or public building

Avoid: Don't go home (they'll know where you live)
       Don't confront unless necessary
```

## 💚 HP Recovery System

The app includes an interactive HP (Health) recovery simulation:

```javascript
// HP Status Animation
Initial State: 30% (Low HP - Visual Warning)
After Recovery: 85% (Recovering)
```

### Recovery Steps

1. **Assess Injuries** - Check for bleeding, broken bones, head trauma
2. **Call for Help** - Dial emergency services
3. **Get to Safety** - Move to secure location
4. **Control Bleeding** - Apply direct pressure with clean cloth
5. **Reduce Swelling** - Apply ice packs for 15-20 minutes
6. **See a Doctor** - Professional medical evaluation
7. **Mental Recovery** - Talk to someone you trust

### Warning Signs Requiring Immediate Medical Attention

- ❌ Difficulty breathing
- ❌ Severe bleeding that won't stop
- ❌ Loss of consciousness (even briefly)
- ❌ Confusion, dizziness, or vision problems
- ❌ Chest or abdominal pain
